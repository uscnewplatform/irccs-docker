= Architettura della Piattaforma
:description: Descrizione dell'architettura a microservizi della piattaforma IRCCS, con servizi, dipendenze e porte esposte.

== Panoramica

La piattaforma IRCCS adotta un'architettura a **microservizi** orchestrata tramite Docker Compose su una rete bridge dedicata (`irccs`). Tutti i servizi comunicano internamente via hostname Docker; solo le porte strettamente necessarie sono esposte sull'host.

== Stack applicativo principale

Il file `docker-compose.yaml` definisce lo stack applicativo core.

=== Rete Docker

Tutti i container applicativi appartengono alla rete bridge `irccs`.

=== Volumi persistenti

[cols="1,2"]
|===

|`postgres_data_hapi`

== Servizi e dipendenze

Il diagramma seguente mostra le dipendenze di avvio tra i container:

[source]
----
postgres-keycloak
      └── irccs-keycloak (healthcheck)
                ├── irccs-microservice-auth
                ├── irccs-microservice-clinical-reasoning
                ├── irccs-microservice-ctcae
                ├── irccs-microservice-practitioner
                ├── irccs-microservice-centro-ricerca
                ├── irccs-microservice-studio-clinico
                ├── irccs-microservice-anagrafica-pazienti
                ├── irccs-microservice-tac
                └── irccs-microservice-zammad

postgres-hapi-fhir
      └── irccs-hapi-fhir

irccs-httpd (no dipendenze dichiarate)
cache / Redis (no dipendenze dichiarate)
----

I microservizi applicativi **attendono il healthcheck di Keycloak** prima di avviarsi, garantendo che l'Identity Provider sia disponibile.

Vedere xref:monitoraggio.adoc[Stack di Monitoraggio] per i dettagli.

== Flusso di autenticazione

[source]
----
Browser / Client
      │
      ▼
Apache HTTPD (porta 80)
      │  (reverse proxy)
      ▼
Microservizi Quarkus
      │  (OIDC token validation)
      ▼
Keycloak (porta 9445) ←→ PostgreSQL (Keycloak DB)
----

Tutti i microservizi validano i token JWT emessi da Keycloak tramite il protocollo OIDC. La policy enforcement viene gestita a livello di ogni microservizio tramite `quarkus-keycloak-policy-enforcer`.
